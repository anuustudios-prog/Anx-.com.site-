Manage editors

Editor account provisioning is disabled until a secure server-side authentication endpoint is configured.

Why is this disabled?

Storing editor passwords in Firestore and checking them in browser JavaScript exposes credentials to users who can inspect client code or database requests. Use Firebase Admin SDK in a Cloud Function to create Firebase Auth users or issue custom tokens, and store only editor profile metadata in Firestore.

After the endpoint is deployed, connect this page to it and use Firebase Auth for editor sessions.
